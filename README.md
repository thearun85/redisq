# redisq - Redis Job Queue - A learning project
A redis based job queue built incrementally to understand distributed systems concepts, redis patterns and asynchronous processing.

## Project Goal
Build a redis-backed job queue from scratch, adding one component at a time to understand how distributed work queues operate at a fundamental level.

# Tech Stack
- **Flask**: REST API for job submission
- **Redis**: Queue backend and state storage
- **Docker**: Container orchestration
- **Python**: Core application logic
